# PyTorch Examples

A small, readable collection of PyTorch examples that you can run, test, deploy and learn from.

- **Five runnable examples** covering autograd, regression, MLP, CNN and LSTM models. Each one trains on synthetic data, so there are no downloads and every run takes seconds on a CPU.
- **A shared training loop** (`fit`) small enough to read in one sitting.
- **A test suite** that checks the building blocks, every example's quality, the CLI, and the notebooks.
- **Example notebooks** in the `notebooks/` folder that walk through the same ideas step by step.
- **A deployable inference server** with a Dockerfile and a compose file.
